🚀 MoonBit とは？ なぜ WebAssembly で注目されるのか？

MoonBit（ムーンビット）は、WebAssembly（WASM）ファーストでゼロから設計された次世代の静的型付けプログラミング言語です。
Rust や Go、C++ など従来の言語と比べ、コンパイル速度が極めて高速で、生成される WASM バイナリが数キロバイト〜数十キロバイトと圧倒的にコンパクトであることが大きな特徴です。

⚡ 1. 超小型・超高速

従来の言語ではランタイムの肥大化により数MBになることも珍しくありませんが、MoonBit は不要なコードを徹底的に削ぎ落とし、わずか数百バイトから動作可能です。

🛡️ 2. 型安全と強力な型推論

Rust や OCaml にインスパイアされた表現力豊かな型システム、パターンマッチング、イミュータブル（不変）デフォルトの設計を持ち、バグを未然に防ぎます。

🌐 3. Web & JS との親和性

標準の WASM (Linear Memory) に加え、ブラウザの GC を活用する wasm-gc や JavaScript への直接トランスパイルにも対応しています。

🛠️ 4. 充実した公式ツールチェーン

ビルドシステム、パッケージマネージャ、フォーマッタ、LSP（言語サーバー）が最初から統合されており、moon コマンドだけで完結します。

📖 解説 & ソースコード (Step 1)

MoonBit では、WASM 向けに関数を公開する際に #export_name("...") アトリビュートを付与します。
パッケージ設定 moon.pkg に pkgtype(kind: "foreign_library") を指定することで、余分なエントリポイントのないクリーンな共有ライブラリが出力されます。

MoonBit ソースコード (src/step1_math/math.mbt)

/// 2つの整数の加算
#export_name("add")
pub fn add(a : Int, b : Int) -> Int {
  a + b
}

/// 再帰によるフィボナッチ計算
#export_name("fib")
pub fn fib(n : Int) -> Int {
  if n <= 1 {
    n
  } else {
    fib(n - 1) + fib(n - 2)
  }
}

JavaScript 側からの呼び出し (app.js)

// 1. WASMファイルをフェッチしてインスタンス化
const response = await fetch('/wasm/step1_math.wasm');
const bytes = await response.arrayBuffer();
const { instance } = await WebAssembly.instantiate(bytes);

// 2. エクスポートされた関数を通常のJS関数と同様に実行
const sum = instance.exports.add(42, 58); // => 100
const fibVal = instance.exports.fib(10);   // => 55

🔤 文字列変換 & 共有メモリインスペクタ

WebAssembly の仕様上、直接文字列オブジェクトを引数や戻り値にすることはできません。

📖 解説: 共有メモリ (Linear Memory) とポインタ

MoonBit で options(link: { "wasm": { "export-memory-name": "memory" } }) を指定すると、WASM の線形メモリがエクスポートされます。

📌 ポインタの正体: WASM におけるポインタは、線形メモリの先頭からのバイトオフセット（Int値）に過ぎません。 MoonBit の組み込み関数 %identity を使うことで、固定長配列 FixedArray[Byte] のメモリアドレスを直接数値として取り出せます。

MoonBit ソースコード (src/step2_string/string.mbt)

// 配列のメモリポインタを取得する内部関数
fn to_ptr(arr : FixedArray[Byte]) -> Int = "%identity"

let in_buf : FixedArray[Byte] = FixedArray::make(4096, b"\x00"[0])
let out_buf : FixedArray[Byte] = FixedArray::make(4096, b"\x00"[0])

#export_name("get_in_buf_ptr")
pub fn get_in_buf_ptr() -> Int { to_ptr(in_buf) }

#export_name("to_upper")
pub fn to_upper(len : Int) -> Int {
  for i = 0; i < len; i = i + 1 {
    let b = in_buf[i].to_int()
    let upper = if b >= 97 && b <= 122 { b - 32 } else { b }
    out_buf[i] = upper.to_byte()
  }
  len
}

JavaScript 側 (TextEncoder / Uint8Array)

// 1. 入力バッファへUTF-8で書き込み
const encoded = new TextEncoder().encode(text);
new Uint8Array(memory.buffer, inPtr, encoded.length).set(encoded);

// 2. WASM関数実行
const outLen = wasm.to_upper(encoded.length);

// 3. 出力バッファからUTF-8デコードして取得
const outBytes = new Uint8Array(memory.buffer, outPtr, outLen);
const result = new TextDecoder().decode(outBytes);

🎨 Canvas 高速ゼロコピー描画

MoonBit 内で 256×256 の RGBA ピクセル配列を直接操作し、JavaScript 側では ImageData としてコピーなしで一瞬で描画します。

1. マンデルブロ集合フラクタル

解像度: 256 × 256 (65,536 px) 描画時間: -- ms

2. コンウェイのライフゲーム (Game of Life)

キャンバスをクリックしてセルを直接配置/反転できます。

シミュレーション速度: -- FPS

📖 解説: ゼロコピー描画のアーキテクチャ

Webブラウザでピクセル単位の描画を行う場合、JavaScript で1ピクセルずつ fillRect を呼ぶと膨大なオーバーヘッドが生じます。
WASMのメモリバッファを直接 Uint8ClampedArray として参照し、ctx.putImageData に渡すことで、GPU転送直前までメモリコピーが一切発生しない超高速描画が実現します。

🎨 メモリレイアウト:
1ピクセルは [R, G, B, A] の連続した4バイト。
256 × 256 × 4 = 262,144 バイト (256 KB) を MoonBit 側のバッファで確保しています。

MoonBit 側 (src/step3_canvas/canvas.mbt)

let pixel_buf : FixedArray[Byte] = FixedArray::make(256 * 256 * 4, b"\x00"[0])

#export_name("get_pixel_buf_ptr")
pub fn get_pixel_buf_ptr() -> Int { to_ptr(pixel_buf) }

#export_name("render_mandelbrot")
pub fn render_mandelbrot(...) -> Unit {
  // 複素数反復計算を行い、pixel_buf[offset + 0..3] に直接色を格納
  pixel_buf[offset + 0] = r.to_byte()
  pixel_buf[offset + 1] = g.to_byte()
  pixel_buf[offset + 2] = b.to_byte()
  pixel_buf[offset + 3] = b"\xff"[0]
}

JavaScript 側 (ゼロコピー描画)

// WASMメモリバッファの上に直接TypedArrayのViewを作成 (コピーなし!)
const ptr = wasm.get_pixel_buf_ptr();
const clamped = new Uint8ClampedArray(wasm.memory.buffer, ptr, 256 * 256 * 4);
const imgData = new ImageData(clamped, 256, 256);

// Canvasへ一括転送
ctx.putImageData(imgData, 0, 0);

🔌 JavaScript FFI (外部関数のインポート)

MoonBit はスタンドアロンで動くだけでなく、ホスト環境 (JavaScript) の関数をインポートして直接呼び出すことができます。
ログ出力や現在時刻取得、DOM操作、非同期通知などを MoonBit 内部からトリガーできます。

合計: --

📖 解説: 外部関数の宣言と ImportObject

MoonBit では、外部シンボルを fn name(args) -> Ret = "module_name" "function_name" の構文で宣言します。

MoonBit ソースコード (src/step4_ffi/ffi.mbt)

// 外部JS関数のインポート宣言 ("env" モジュールから供給)
fn js_log_number(tag : Int, val : Int) -> Unit = "env" "js_log_number"
fn js_get_time() -> Double = "env" "js_get_time"

#export_name("run_ffi_calc")
pub fn run_ffi_calc(n : Int) -> Int {
  let start = js_get_time() // JS側の現在時刻を取得
  let mut sum = 0
  for i = 1; i <= n; i = i + 1 {
    sum = sum + i
    if i % 5 == 0 {
      js_log_number(2, sum) // JS側ログ関数を呼び出し
    }
  }
  sum
}

JavaScript 側での関数注入 (Import Object)

const importObject = {
  env: {
    js_log_number: (tag, val) => {
      console.log(`[Tag ${tag}] Value: ${val}`);
    },
    js_get_time: () => performance.now()
  }
};

// インスタンス化時に関数を渡す
const { instance } = await WebAssembly.instantiate(bytes, importObject);
